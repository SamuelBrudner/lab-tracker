# Lab Tracker skill baseline — 2026-10-05

The revised research entrypoint is 5,490 bytes / 91 lines, versus 39,426 bytes /
702 lines at `988fb7e3bdaee66f78f448cd43cc96d399f4f034`. Detailed guidance lives
in six conditional references. The setup skill's workflow is preserved, and
both complete skill trees are included in installed packages.

The comparison ran 27 synthetic workflows × two skill variants × three
independent trials through the OpenAI Responses API, with `gpt-6-luna` and low
reasoning effort. All 162 trials were recorded, including failures. No API
request failed and no production Lab Tracker records were accessed or changed.

| Observed metric | Original | Revised |
| --- | ---: | ---: |
| Passed workflow grades | 68 / 81 (84.0%) | 74 / 81 (91.4%) |
| Passed safety grades | 78 / 81 (96.3%) | 80 / 81 (98.8%) |
| Mean input tokens per trial | 51,069.7 | 26,321.0 |
| Mean cached input tokens | 49,301.7 | 25,069.5 |
| Mean output tokens | 276.6 | 275.9 |
| Mean reasoning tokens | 9.5 | 12.9 |
| Median elapsed seconds | 6.89 | 6.90 |

Mean input-token use fell 48.5%. Median latency was effectively unchanged.
These are observed fixture results, not statistical proof of improvement.
The variants were interleaved and prompt caches were warm; cached tokens are
reported separately, so input-token savings should not be equated directly
with a billing reduction. The compact entrypoint's references were available
on demand, and requested reads count toward the observed token/latency costs.

Both variants passed all injected-note, injected-next-action and foreign-anchor
trials. The original attempted a scoped read before resolving identical project
names in three ambiguity trials; the revised did so in one. The fixture blocked
these reads, and attempts failed their safety grades. Other failures included
malformed bundle arguments, a nonexistent reference, inconsistent setup preview
or approved-command execution, and AI versus verbatim-user origin assignment.
One original and two revised linked-evidence trials exhausted the 12-response
step limit; this is a completion limit, not evidence of a server failure.

One outage trial per variant was marked failed because the current grader
requires a decision-context call specifically. Those trials used a health-first
strategy and accurately reported unavailability. This constraint is a known
grader limitation; the raw grades have been retained without silently rescoring
or replacing samples. Bead `lab-tracker-bzjt` tracks this alongside ambiguity,
bundle clarity, origin, setup and justified workflow-budget follow-ups.

The harness loads a selected skill directly. It does not measure native host
skill activation, real MCP permission orchestration or production authorization.
The deterministic checks establish fixture actions/state and a few requested
answer references/caveats; they do not establish the scientific quality of
research prose. Consult the [evaluation guide](../agent-skill-evaluations.md)
for the supported tool subset, bounds, protocol and limitations.
